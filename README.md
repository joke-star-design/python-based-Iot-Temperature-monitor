# Python-Based IoT Temperature Monitoring System

## Project Description
This project simulates an IoT temperature monitoring system using Python.

## Features
- Generates 50 temperature readings.
- Saves readings in a CSV file.
- Reads and validates temperature data.
- Calculates average temperature.
- Displays warnings when temperature exceeds 35°C.
- Creates a temperature graph using Matplotlib.

## Tools Used
- Python
- CSV
- Matplotlib
- Google Colab

## Files
- temperature_monitor.py
- temperature_data.csv
- temperature_graph.png
